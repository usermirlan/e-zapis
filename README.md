# Очередь в поликлинику (Clinic Queue System)

Полнофункциональная система онлайн-записи к врачам на базе Python (Django) и Bootstrap 5.

## Основной функционал
- Удобный и красивый пользовательский интерфейс (UI/UX).
- Регистрация и авторизация пациентов.
- Каталог медицинских услуг и врачей.
- Автоматическая генерация расписания работы врачей.
- Запись на свободные слоты (время).
- **Автогенерация номера очереди** на каждый день.
- Личный кабинет с возможностью просмотра и отмены своих записей.
- Профессиональная админ-панель для управления клиникой.

## Запуск проекта

Убедитесь, что у вас установлен Python (протестировано на версии 3.10+).

1. Перейдите в папку с проектом:
   ```bash
   cd c:\Users\mirla\OneDrive\Desktop\pro\clinic_queue
   ```

2. Установите зависимости (если еще не установлены):
   ```bash
   pip install django djangorestframework django-cors-headers pillow
   ```
   *(Примечание: в текущей версии проект работает на стандартных шаблонах Django и работает даже без DRF/CORS, если они не установлены из-за конфигурации сети).*

3. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
